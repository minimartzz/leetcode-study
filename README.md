## :star2: About the Project

A collection of leetcode solutions organised by difficulty. Each file includes the tags associated, problem description, and solution explanation as well as test cases.

## :file_folder: Project Structure

```
template.py           # Template for solutions
src/
├── easy              # Easy question solutions
├── medium            # Medium question solutions
├── hard              # Hard question solutions
```

## :computer: Setup

```bash
# Install dependencies
uv sync --all-extras

# Run individual solutions
uv run src/easy/<file>.py

# Run test cases
uv run pytest src/easy/<file.py>
```
